1. Child-Pugh 分級

用途：估計肝硬化病人的肝功能儲備，預測手術（尤其肝切除、腹部手術）與短期存活。

組成（5 項，各 1–3 分，總分 5–15）

項目 1 分 2 分 3 分
總膽紅素 (mg/dL) <2 2–3 >3
血清白蛋白 (g/dL) >3.5 2.8–3.5 <2.8
INR（或 PT 延長秒數） <1.7（<4） 1.7–2.3（4–6） >2.3（>6）
腹水 無 輕度／利尿劑可控 中重度／難治
肝性腦病 無 Grade 1–2 Grade 3–4

分級：A 5–6｜B 7–9｜C 10–15

適用族群：已確診肝硬化者。不適用於急性肝炎、非肝硬化門脈高壓、單純膽道阻塞（膽紅素被阻塞因素灌水）。

限制 - 腹水與肝性腦病是主觀判定，觀察者間一致性差。 - 白蛋白會被輸注白蛋白、腎病症候群、營養狀態干擾。 - INR 受不同實驗室 thromboplastin 差異影響（這正是 MELD 改用 INR 標準化仍被詬病之處）。 - 有天花板效應：三個都達 3 分就無法再區分嚴重度。 - 不含腎功能，而肝腎症候群是肝硬化最致命的併發症之一。

國考陷阱 1. 「Child-Pugh 包含下列何者？」選項放 creatinine → 錯，那是 MELD。 2. 放 AST/ALT → 錯，Child-Pugh 完全不看轉胺酶（肝細胞壞死程度 ≠ 肝功能儲備）。 3. 「膽紅素>3、白蛋白<2.8、INR>2.3」不是自動 Class C，還要加腹水與腦病才算總分。 4. 原始 Child-Turcotte 用的是營養狀態，Pugh 改成 PT/INR — 偶爾考沿革。

臨床決策連結 - Child A：可考慮肝切除（再加上 portal pressure 與 bilirubin 評估）。 - Child B/C：肝切除風險陡升 → 轉向移植評估或局部治療。 - Child C 合併腹水／腦病：非緊急手術原則上避免。 - 抗病毒藥物選擇：Child B/C 者避免用會惡化的方案（例如失代償肝硬化不用 protease inhibitor 類 HCV 藥）。

2. MELD / MELD-Na / MELD 3.0

用途：預測末期肝病三個月死亡率，用於肝移植等候名單排序。原始開發目的其實是預測 TIPS 術後存活，2002 年才被 UNOS 採用為器官分配依據 — 這個沿革是考點。

公式（MELD）

MELD = 3.78×ln(總膽紅素) + 11.2×ln(INR) + 9.57×ln(creatinine) + 6.43
  • 任一數值 <1.0 一律以 1.0 代入（避免 ln 為負）。
  • creatinine 上限 4.0 mg/dL；一週內接受 ≥2 次透析者，creatinine 直接以 4.0 代入。

演進 | 版本 | 新增 | 為什麼要改 | |—|—|—| | MELD-Na（2016 採用） | 血鈉 | 低血鈉本身是死亡率獨立因子，反映稀釋性低鈉與循環失能 | | MELD 3.0（2023 採用） | 女性校正、白蛋白 | 原公式低估女性死亡率（creatinine 受肌肉量影響），造成女性等候不利 |

適用族群：≥12 歲末期肝病。兒童用 PELD（含年齡、身高／體重、白蛋白、膽紅素、INR、生長遲滯）。

限制 - 不含腹水、肝性腦病、營養狀態、生活品質。 - 對難治性腹水、反覆靜脈曲張出血、嚴重搔癢、肝肺症候群等「MELD 分數低但很痛苦」的病人會低估 → 需靠 exception points。 - creatinine 受肌肉量、性別、營養影響。 - 不適用於急性肝衰竭（那用 King’s College criteria）。

國考陷阱 1. 「MELD 包含下列何者？」放 腹水／肝性腦病 → 錯。 2. 誤以為 MELD 分數越高越適合手術 — 相反，MELD ≥15 才有移植存活優勢（低於此，移植的風險大於留在名單上）。 3. 忘記透析病人 creatinine 代 4.0。

臨床決策連結 - MELD ≥15：移植帶來存活利益的門檻。 - MELD ≥21 或 Maddrey DF ≥32：重症酒精性肝炎，考慮類固醇。 - 非肝臟手術風險評估：MELD >20 死亡率顯著上升。

3. ALBI grade（Albumin–Bilirubin）

用途：只用白蛋白與膽紅素兩個客觀數值評估肝功能，避開 Child-Pugh 的主觀項目。 主要用在 HCC 病人分層（尤其 Child A 內部再細分）。

等級 意義
ALBI 1 肝功能最好
ALBI 2 中等
ALBI 3 差

限制：不含腎功能與凝血；不是分期系統，不能取代 BCLC。 決策連結：Child A 但 ALBI 2 的病人接受 TACE 或標靶治療的耐受性明顯較差 — 近年文獻的重點。

4. 上消化道出血三兄弟：Glasgow-Blatchford / Rockall / AIMS65

Glasgow-Blatchford (GBS) Rockall AIMS65
何時算 內視鏡前 pre 版可術前算，完整版需內視鏡後 入院即可
組成 BUN、Hb、收縮壓、脈搏、黑便、昏厥、肝病、心衰竭 年齡、休克、共病＋（內視鏡診斷、出血徵象） Albumin<3.0、INR>1.5、Altered mental status、SBP≤90、age>65
預測什麼 需不需要介入（輸血、內視鏡治療、手術） 再出血與死亡率 院內死亡率
關鍵切點 GBS ≤1 → 可門診處理（低風險） 完整 Rockall ≥5 高風險 ≥2 分死亡率明顯上升

國考陷阱 1. 問「哪個分數用來決定病人能不能不住院」→ Glasgow-Blatchford，不是 Rockall。 2. GBS 不含年齡；Rockall 含年齡 — 這是最愛考的區分點。 3. AIMS65 預測死亡不是再出血。

5. Forrest 分級（消化性潰瘍出血）

分級 內視鏡所見 未治療再出血率（概略） 處置
Ia 噴射狀動脈出血 ~55% 內視鏡止血（雙重療法）＋高劑量 PPI
Ib 滲血 ~50% 同上
IIa 可見裸露血管 ~43% 內視鏡止血
IIb 附著血塊 ~22% 沖洗／移除血塊後評估，暴露出 Ia–IIa 則治療
IIc 平坦色素斑 ~10% 不需內視鏡止血
III 乾淨潰瘍底 ~5% 不需止血，可早期進食、早期出院

適用族群：消化性潰瘍出血。不適用於靜脈曲張出血（那看 Sarin 分類與 Baveno 準則）、Dieulafoy、Mallory-Weiss。

限制：觀察者間一致性中等（尤其 IIb 與 IIc）；不含病人全身狀況與共病。

國考陷阱 1. Forrest III 給予內視鏡治療 → 錯，反而增加風險且無益。 2. IIb（附著血塊）是最有爭議的一格，題目常設計成「該不該沖掉血塊」。 3. 拼字：是 Forrest（雙 r），不是 Forest。

決策連結：Ia–IIa → 內視鏡治療後 IV PPI（bolus + infusion 或高劑量間歇）72 小時；IIc/III → 口服 PPI、早期進食、考慮早期出院。

6. 急性胰臟炎：Ranson / BISAP / Revised Atlanta / CTSI

Ranson criteria

  • 入院時 5 項：年齡>55、WBC>16000、glucose>200、AST>250、LDH>350。
  • 48 小時內 6 項：Hct 下降>10%、BUN 上升>5、Ca<8、PaO₂<60、base deficit>4、體液滯留>6L。
  • 必須等 48 小時才完整 — 這是最大限制，也是最常考的陷阱。
  • 膽石性胰臟炎有另一套略不同的切點。

BISAP（24 小時內）

BUN>25、Impaired mental status、SIRS、Age>60、Pleural effusion。≥3 分死亡率顯著上升。

Revised Atlanta 2012（這是定義不是預測分數）

嚴重度 定義
輕度 無器官衰竭、無局部或全身併發症
中重度 暫時性器官衰竭（<48 小時）或局部／全身併發症
重度 持續性器官衰竭（>48 小時）

局部併發症術語也一併更新：<4 週為 acute peripancreatic fluid collection／acute necrotic collection；>4 週有包膜者為 pseudocyst／walled-off necrosis。

CTSI（Balthazar + 壞死程度）

  • 太早（<72 小時）做 CT 會低估壞死範圍，這是影像題常考的判讀陷阱。

國考陷阱 1. 「入院當下可用何者評估嚴重度」→ 不能選 Ranson（要 48 小時）。 2. 器官衰竭 48 小時是中重度與重度的分水嶺。 3. 血中 amylase／lipase 的高低與嚴重度無關 — 常被設計成誘答。

7. Tokyo Guidelines 2018（TG18）

急性膽囊炎

  • 診斷：A 局部發炎徵象（Murphy sign、右上腹痛／腫塊）＋ B 全身發炎（發燒、CRP↑、WBC↑）＋ C 影像所見。 A+B 疑似，A+B+C 確診。
  • 嚴重度：Grade I 輕度｜Grade II 局部發炎嚴重（WBC>18000、可觸及腫塊、症狀>72 小時、明顯局部併發症）｜Grade III 合併器官功能障礙。

急性膽管炎

  • 診斷：A 全身性發炎 ＋ B 膽汁鬱積（黃疸、肝功能異常）＋ C 影像（膽管擴張、病因）。
  • Grade III：合併器官功能障礙（低血壓需升壓劑、意識改變、PaO₂/FiO₂<300、Cr>2.0、INR>1.5、血小板<10 萬）。

國考陷阱 1. Charcot triad（發燒、黃疸、右上腹痛）敏感度低（約 26–72%），不能拿來排除膽管炎； Reynolds pentad（再加低血壓、意識改變）代表重症。 2. Grade III 膽管炎的正解是緊急膽道引流（ERCP）＋支持治療，不是「先抗生素觀察」。 3. 輕度膽囊炎的手術時機：早期腹腔鏡膽囊切除（發病 72 小時內）優於延遲手術。

8. 肝細胞癌：BCLC 與 Milan criteria

BCLC（Barcelona Clinic Liver Cancer）

唯一同時整合腫瘤負荷、肝功能、體能狀態並直接連到治療的分期系統 — 這句話本身就是考點。

分期 腫瘤 肝功能／PS 首選治療
0（極早期） 單顆 <2 cm Child A、PS 0 切除／燒灼
A（早期） 單顆或 ≤3 顆且各 ≤3 cm Child A–B、PS 0 切除／移植／燒灼
B（中期） 多發、無血管侵犯 Child A–B、PS 0 TACE（近年加入全身治療合併策略）
C（進展期） 血管侵犯或肝外轉移 Child A–B、PS 1–2 全身治療（免疫合併抗血管新生為第一線）
D（末期） 任何 Child C、PS >2 支持療法／移植評估

2022 年更新引入 treatment stage migration 與「非最佳候選者」概念：同一期別內可依個別條件上下移動。

Milan criteria（移植適應症）

單顆 ≤5 cm，或 ≤3 顆且每顆 ≤3 cm，無大血管侵犯、無肝外轉移。 - UCSF criteria 為放寬版本。 - 陷阱：Milan 是移植適應症，不是射頻燒灼或切除的適應症。

9. 肝性腦病：West Haven

級別 表現
Minimal (covert) 只有心理計量測驗異常，臨床看不出來
I 注意力下降、睡眠週期改變、輕微人格改變
II 嗜睡、定向障礙、明顯撲翼樣震顫
III 昏睡但可喚醒、明顯混亂
IV 昏迷

陷阱：撲翼樣震顫（asterixis）在 Grade IV 反而消失（因為病人已無自主肌張力）， 「昏迷病人沒有 asterixis 所以不是肝性腦病」是典型錯誤推論。

10. 酒精性肝炎：Maddrey DF 與 Lille score

  • Maddrey Discriminant Function = 4.6 ×（PT − 對照 PT）＋ 總膽紅素。 DF ≥32 → 重症，考慮 prednisolone 40 mg/day 28 天。
  • Lille score：治療第 7 天評估反應，≥0.45 代表無反應 → 停用類固醇，避免感染風險。
  • 使用類固醇前必須排除活動性感染、消化道出血、腎衰竭。

11. 急性肝衰竭：King’s College Criteria

乙醯胺酚中毒 非乙醯胺酚
pH <7.3（補液後）或 同時具備 PT>100 秒（INR>6.5）、Cr>3.4、Grade III–IV 腦病 PT>100 秒（INR>6.5）單獨即可，或以下五項中任三項：年齡<10 或>40、病因為非 A 非 B 肝炎／藥物、黃疸至腦病>7 天、PT>50 秒、膽紅素>17.5

陷阱：兩套準則完全不同，題目常用乙醯胺酚的數字套到病毒性肝炎。

12. 食道：Chicago v4.0、LA classification、Prague C&M

  • Chicago Classification v4.0（高解析度測壓）：achalasia I 型（無蠕動）、II 型（全食道加壓，治療反應最好）、III 型（痙攣型，最難治）。
  • LA classification（逆流性食道炎黏膜破損）：A（≤5 mm）、B（>5 mm 不連續）、C（跨黏膜皺襞但 <75% 周徑）、D（≥75% 周徑）。 C/D 才算確診 GERD 的客觀證據（Lyon consensus）。
  • Prague C&M：Barrett 食道的環周長度 C 與最大長度 M。不含分化不良分級，dysplasia 要另外病理報告。

13. 發炎性腸道疾病：Montreal、Truelove-Witts、Mayo、CDAI

  • Montreal：克隆氏症 A（年齡）L（部位 L1 迴腸／L2 大腸／L3 迴結腸／L4 上消化道）B（行為 B1 非狹窄非穿透／B2 狹窄／B3 穿透，＋p 肛周）；潰瘍性結腸炎 E1 直腸／E2 左側／E3 廣泛。
  • Truelove-Witts：UC 急性期嚴重度（排便次數、血便、發燒、心搏、貧血、ESR）→ 重度者需住院靜脈類固醇。
  • Mayo score：UC 疾病活動度與治療反應（含內視鏡次分數，臨床試驗常用）。
  • CDAI / Harvey-Bradshaw：克隆氏症活動度，HBI 是簡化版。

陷阱：Truelove-Witts 只用於 UC；把它套到克隆氏症是常見誘答。

15. 這一章怎麼被考：三種常見題型

  1. 組成題：「下列何者不是Child-Pugh 的項目？」→ 熟記五項與 MELD 三（四）項的差異。
  2. 時機題：「入院當下最適合用哪個分數？」→ 考 Ranson 需 48 小時、GBS 可術前算。
  3. 決策題：給臨床情境問下一步 → 分數只是中介，真正要答的是處置（例如 TG18 Grade III 膽管炎 → 緊急引流）。
測驗題原始碼
Q: 68 歲男性肝硬化病人，總膽紅素 3.5 mg/dL、白蛋白 2.6 g/dL、INR 2.5、中度腹水、意識清楚。下列敘述何者正確？
A) Child-Pugh 為 Class B
B) 需再測 creatinine 才能算出 Child-Pugh 分數
C) Child-Pugh 為 Class C，肝切除風險極高
D) 因無肝性腦病，Child-Pugh 最高只能到 Class B
ans: C
why: 膽紅素>3 得 3 分、白蛋白<2.8 得 3 分、INR>2.3 得 3 分、中度腹水 2 分、無腦病 1 分，共 12 分為 Class C。Child-Pugh 不含 creatinine（B 錯），單項無異常不會限制總級別（D 錯）。

Q: 55 歲男性因解黑便入院，血壓 100/60 mmHg、脈搏 105 次/分、Hb 9.8 g/dL、BUN 35 mg/dL。急診醫師想決定病人可否安排門診追蹤而不住院，最適合使用下列何者？
A) Rockall score
B) Glasgow-Blatchford score
C) Forrest classification
D) AIMS65
ans: B
why: GBS 是內視鏡前的風險分層工具，≤1 分可考慮門診處理。Rockall 完整版需內視鏡結果，Forrest 需內視鏡所見，AIMS65 預測死亡率而非是否需介入。

Q: 急性胰臟炎病人入院 36 小時後仍有持續低血壓需升壓劑支持。依 2012 修訂版 Atlanta 分類，此時最適當的描述為何？
A) 重度急性胰臟炎
B) 中重度急性胰臟炎，若器官衰竭於 48 小時內緩解
C) 輕度急性胰臟炎合併局部併發症
D) 需等 Ranson 分數滿 48 小時才能分類
ans: B
why: Atlanta 2012 以器官衰竭是否持續超過 48 小時區分中重度與重度。36 小時尚未跨過 48 小時門檻，須待後續是否緩解才能定論；Atlanta 是定義而非預測分數，不需等 Ranson。
