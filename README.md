# 消化科國考知識庫（網站版）

台灣醫師國考消化科知識庫的靜態網站輸出。

- 語料：考選部公開考畢試題 111-1 ～ 115-2 共 5,200 題，其中 446 題判定為消化科核心考點
- 內容：疾病章節、分級系統總表、高鑑別度比較表、近五年 100 大考點、自我測驗
- 圖譜：34 張，全部取自 Wikimedia Commons 且僅收 PD／CC0／CC BY／CC BY-SA，頁面內標注來源、作者與授權

## 說明

- 本 repo 只存放**建置後的網站**，不含題庫語料與 pipeline。
- 題目與答案為考選部公開資料；詳解、表格、口訣、圖說均為自撰整理，**非官方詳解**。
- 內容僅供個人學習參考，不作為臨床決策依據。
- 已設定 `noindex`，不希望被搜尋引擎收錄。

原始專案（含 pipeline 與語料）不公開。
